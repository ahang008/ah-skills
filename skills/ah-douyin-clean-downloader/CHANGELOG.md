# Changelog

## ah-douyin-clean-downloader v0.1.0

首个公开版本。

### 已实现

- 接收抖音官方链接或完整分享口令。
- 获取平台提供的无抖音角标 H.264 播放源。
- 保留下载源中的原始视频和音频，不转码。
- 在桌面媒体库中按博主自动建立文件夹。
- 避免覆盖同名文件。
- 使用 ffprobe 验证时长、编码和音视频流。
- 不调用付费解析 API，不保存 Cookie、账号或密钥。
- 包含 14 项自动测试和环境自检脚本。

### 使用边界

- 仅用于本人拥有或已经获得授权的视频。
- 不擦除作者上传前已经烧录进画面的 Logo、字幕或贴片。
- 平台接口变化可能导致后续版本需要维护。
- 当前采用源码可见、非商业使用许可证，不属于 OSI 认可的开源许可证。
