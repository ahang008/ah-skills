# 故障排查

## 没有识别到官方链接

- 确认输入中包含 `https://v.douyin.com/...` 或其他抖音官方 HTTPS 链接。
- 不要传入截图中的文字或被中间站改写的链接。

## 网络请求失败

- 运行 `python3 scripts/doctor.py --format text`。
- 确认 `curl` 可用。
- 如当前网络需要代理，显式设置 `AH_DOUYIN_PROXY`。
- 不要为了修复单条视频而修改系统代理或安装未知证书。

## 作品不存在或触发风控

可能原因包括作品已删除、作品私密、平台限频或元数据端点变化。不要请求用户提供账号密码或 Cookie。

## 没有找到 H.264 播放源

先保存经脱敏的字段结构，确认平台是否调整了 `play_addr_h264`、`play_addr` 或 `bit_rate`。不得把 `download_addr` 当作后备源。

## ffprobe 不存在

脚本仍可下载，但只做 MP4 文件头校验，无法返回准确时长、编码和音频流数量。
