# 阿杭减肥视频制作入口

这是阿杭系列工作流的公开精简入口。原生剪辑依赖另行安装的 `yichen-jianying-edit`。本目录不包含第三方引擎、稿定模板、缓存资源、素材或完整后端。

## 选择本次范围

- 参数按当前明确要求、本会话已确认要求、本系列既有预设依次选择。阿杭减肥系列的完整实操预设包含1.2倍速、字幕同步、白字黑边胸口字幕、连续覆盖，以及范围内已经确认的配乐。其他使用者按自己的要求设置。
- 只要基础草稿，或已明确原速、无音乐、不要导出时，按本次范围执行。封面与成片仅在已经要求时制作。
- 正式资产归用户 `Movies/减肥/序号-主题/`。现有主题返工接续原目录，源素材保持原位；不把本系列参数传播到AI博主系列。

## 调用独立依赖

1. 从当前环境的 Skill 索引或安装目录定位 `yichen-jianying-edit/SKILL.md`，本次重新读取并遵循其依赖检查、剪辑质检及原生验收流程。缺少依赖时只报告缺项；不复制、替代或绕过引擎。
2. 将本次范围和系列参数交给引擎。语义、停顿、切口、字幕同步和音频质检由引擎一处维护，入口不维护第二份通用剪辑规则。
3. 已要求封面时读取当前安装引擎的减肥系列预设及封面交付说明，复用用户已确认且已授权的模板。未安装相关流程或没有已授权模板时报告缺项，不以仿制图片代替指定封面成果。
